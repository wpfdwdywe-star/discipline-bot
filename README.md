# 交易纪律机器人

**策略你自己定，纪律交给机器执行。**

大多数人亏钱不是因为看错，而是因为不守自己定的规矩：跌破止损位舍不得卖，把止损位越挪越低，卖飞了又忍不住追高。这个机器人替你盯 A 股持仓，到点就提醒，并且**不让你给自己找借口**。

- 不碰你的证券账户，不下单，只盯盘、提醒、记账
- 提醒推送到**微信**（通过 [PushPlus](https://www.pushplus.plus)），也有网页面板，手机电脑都能看
- 每次违反纪律都记下来，月底出报告，用数据告诉你"临时改主意"到底是帮了你还是坑了你

> ⚠️ **免责声明**：本项目是纪律辅助工具，不是投资建议。规则、提醒和"看法"都基于公开数据的固定规则计算，可能出错、可能延迟。数据来自免费公开接口，不保证准确和及时。任何交易决定和盈亏由你自己负责。

## 它能做什么

### 1. 止损纪律（核心）

```
建仓     输入股票代码 → 机器人自动找出现价下方的横盘平台 → 你选一个作为止损位 → 锁定
第1天    收盘价跌破止损位 → 进入观察期（不看量能，缩量跌破也算）
第2天    14:40 检查：现价 ≥ 止损位 且 ≥ 分时均价 → 有效收回，解除观察
                    否则 → 🔴 清仓信号，14:57 前必须卖
没卖     每 3 分钟催一次；拖过一个交易日记违规
```

- **止损位只能上移，不能下移**。想往下挪会被拒绝，并记一次违规
- 手动改数据文件会被检测到（文件带哈希封条），同样记违规
- 分红送转时自动按比例调整止损位，这是唯一允许的下调

**支撑位怎么算**：横盘 = 区间振幅 ≤ 10%，至少 3 个交易日；支撑位取平台的最低收盘价。3–9 天是小支撑，10–19 天是中支撑，20 天以上是大平台。

### 2. 减仓回补

止盈卖出一部分后，等它回落到位再买回，**防止追高**：

```
减仓     录入卖出价 → 机器人列出卖出价下方的平台 → 选一个作为回补价 → 锁定（只能下调）
回落     收盘进入回补区（回补价上方 3% 以内）→ 🔵 开始观察
企稳     连续 3 天收盘不破回补价 → 🟢 可以买回
跌穿     收盘跌破回补价 → ⛔ 支撑失效，别接飞刀，并列出下方更低的平台
买回     止损位自动上移到回补价，买回的仓位同样受止损纪律管
```

### 3. 盘中监控（交易时段每 5 分钟）

上午走势权重低（多是开盘情绪），所以上午门槛更高，一般情况攒到 13:00 一起发：

| | 上午 | 下午 |
|---|---|---|
| 🔴 严重：盘中跌破止损位 | ≥ 5% | ≥ 3% |
| 🔴 严重：单日跌幅 | ≥ 9% | ≥ 7% |
| 🔴 严重：之前的清仓信号还没执行 | 始终 | 始终 |
| 🟡 一般：小幅跌破止损位、跌 5%+、到回补区、跌破回补价、上午放量 | 13:00 汇总 | 直接发 |

每种情况每只股票每天只提醒一次。**正式判断仍以 14:40 和收盘价为准**，盘中提醒只是让你提前有数。

### 4. 收盘简报

每个交易日收盘后推送一份简报：沪深300、每只持仓的价格、离止损位多远、均线（MA20/60/250）、量比、最新财报，再加一句**看法**：

- **风险信号**：周五收盘跌破年线、净利润连续两期同比下滑、营收同比负增长、ROE 比去年同期降超过 3 个百分点
- **注意信号**：扣非净利润连续下滑、短期走弱、离止损位不到 3%
- 2 项以上风险信号 → "清仓风险偏高"；1 项 → "继续观察"；没有 → "继续持有"

### 5. 防止你把它关掉

- 交易日早上推送"☀️ 在岗"（9:15 起；休眠服务器在 9:20 被唤醒时发）。**哪天没收到，就说明它被关了**
- 停机期间错过了 14:40–15:30 的检查：人为停止记**违规**，服务器故障或休眠记**故障**

### 6. 数据延迟保护

- 分钟线落后超过 3 分钟就不拿来判断，换备用数据源，每分钟重试；到 14:52 还不新鲜，就用最新能拿到的判断，并在提醒里注明延迟
- 收盘后当天日K还没出来，每 5 分钟重试一次，到 17:00 才按停牌处理

## 安装

需要 **Python 3.10+** 和一个 **PushPlus token**：打开 [pushplus.plus](https://www.pushplus.plus)，微信扫码登录，关注公众号，在"一对一推送"页面复制 token。

### 方式一：云服务器（推荐）

放在服务器上，你关不掉它，才能真正监督你。支持 Ubuntu 22.04+ / Debian 12+。

```bash
git clone <本仓库地址> discipline-bot
cd discipline-bot
sudo bash install.sh        # 按提示填 PushPlus token 和网页登录密码
```

装完会显示面板网址。打不开的话，去云服务商控制台的防火墙/安全组放行 TCP 8765 端口。

- 开机自启，崩溃 10 秒后自动重启
- 更新：`git pull && sudo bash install.sh`，持仓和日志都会保留
- 日志：`sudo journalctl -u discipline-bot -f`

### 方式二：会自动休眠的免费服务器（如 instabox）

免费服务器闲置一段时间就会暂停，暂停期间机器人不运行。`install.sh` 在 instabox 上会自动发布一个公开 HTTPS 网址，访问这个网址就能唤醒机器。接下来用 [cron-job.org](https://cron-job.org)（免费）定时去敲门：

```bash
# cron-job.org 注册后，在 Settings → API 生成 key
python scripts/setup_wakeup.py --key 你的key --url https://你的面板地址/healthz
```

这会建好 5 个任务：交易日 9:20–11:30、13:00–16:55 每 5 分钟敲一次门，中午休息，连续叫不醒会发邮件。

针对休眠做过的处理：唤醒后先用网络时间校正时钟，数据放在持久化磁盘 `/data`，进程没恢复的话由系统服务自动拉起并补做检查。

### 方式三：Mac 本地试用

双击 `启动纪律机器人.command`。第一次运行会自动安装依赖，然后打开 `http://127.0.0.1:8765`。

本地运行时，强提醒会用 Mac 系统弹窗（不点掉不会消失）+ 警报声 + 语音播报。**但终端窗口关了它就停了**，正式使用建议放到服务器上。

## 配置

`config.json`（第一次安装时自动生成，**不要提交到 Git**，`.gitignore` 已经排除）：

```json
{
  "pushplus_token": "PushPlus 的 token",
  "serverchan_key": "可选，Server酱 的 SendKey",
  "password": "网页面板密码（对外开放时必填）",
  "host": "0.0.0.0",
  "port": 8765
}
```

规则参数在代码里，改之前先跑一遍测试：

| 参数 | 位置 | 默认值 |
|---|---|---|
| 横盘振幅、最少天数、支撑级别 | `rules.py` 顶部 | 10%、3 天、10/20 天 |
| 放量倍数 | `rules.py` `VOLUME_RATIO` | 5 日均量 × 1.5 |
| 回补区宽度、企稳天数 | `rules.py` `REBUY_ZONE` / `REBUY_STABLE_DAYS` | 3%、3 天 |
| 盘中严重门槛 | `rules.py` `DEEP_BREAK` / `BIG_DROP` | 见上表 |
| 简报风险信号 | `analysis.py` | 见上文 |
| 各项检查时间 | `core.py` `Scheduler` | 见上文 |

## 文件说明

| 文件 | 作用 |
|---|---|
| `rules.py` | 纪律规则：平台识别、跌破、收回、回补、盘中事件（纯计算，不联网） |
| `analysis.py` | 收盘简报的趋势和财报分析（纯计算） |
| `data.py` | 行情和财报数据（AKShare，新浪优先，东方财富备用） |
| `core.py` | 持仓管理、定时检查、调度器 |
| `store.py` | 持仓状态、事件日志、防篡改封条 |
| `notify.py` | 微信推送、Mac 系统提醒 |
| `app.py` + `ui.html` | 网页面板 |
| `bot.py` | 命令行（可选） |
| `install.sh` | 服务器一键安装 |
| `scripts/setup_wakeup.py` | cron-job.org 定时唤醒一键配置 |

## 开发和测试

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q tests
```

测试不联网：行情和推送都是模拟的。

## 已知限制

- 只支持 A 股个股；数据来自免费公开接口，接口改版时可能取数失败（先试 `pip install -U akshare`）
- 网页面板用的是 Flask 自带服务器，适合个人使用；面板网址加密码就能看到全部持仓，不要外传
- 平台识别是固定规则，不一定跟你肉眼看的一致，所以建仓时会列出几个候选让你选，也可以手动输入
- 没有自动下单。卖出由你手动操作，然后在面板上点"已清仓"或"减仓"
